# Project Summary

## Overview of Technologies Used
This project is built using the following languages, frameworks, and libraries:

- **Languages**: Java, JavaScript, SQL
- **Frameworks**: Spring Boot for the backend, Vue.js for the frontend
- **Main Libraries**: 
  - Spring Boot for building the backend RESTful API
  - Vue Router for routing in the Vue.js application
  - Axios (implied in request.js) for making HTTP requests in the frontend

## Purpose of the Project
The purpose of this project appears to be the development of a web application that manages various functionalities related to agritainment, user management, and information dissemination. It likely serves as a platform to facilitate interactions between users and agritainment services, allowing for actions such as applying for projects, managing orders, and accessing information.
