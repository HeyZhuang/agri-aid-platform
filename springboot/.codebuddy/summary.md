# Project Summary

## Overview of Technologies
The project is built using the following technologies:
- **Programming Language**: Java
- **Framework**: Spring Boot
- **Main Libraries**: 
  - Spring Framework (for dependency injection and web functionalities)
  - MyBatis (for data access and ORM)

## Purpose of the Project
The purpose of the project is to create a web application that serves various functionalities related to user management, agritainment services, and other administrative tasks. It aims to facilitate operations such as managing users, goods, orders, and policies, while also handling exceptions and configurations to ensure a smooth user experience.

## Configuration and Build Files
The following files are relevant for the configuration and building of the project:

- **Build File**:
  - `/pom.xml` (Maven configuration file)

- **Configuration Files**:
  - `/src/main/resources/application.yml` (Application configuration settings)

## Source Files Location
The source files can be found in the following directories:

- `/src/main/java/com/example` (Main application package)
- `/src/main/java/com/example/common` (Common utilities and configurations)
- `/src/main/java/com/example/controller` (Controllers for handling web requests)
- `/src/main/java/com/example/entity` (Entity classes representing database tables)
- `/src/main/java/com/example/enums` (Enumeration classes for various constants)
- `/src/main/java/com/example/exception` (Custom exception handling)
- `/src/main/java/com/example/mapper` (Data access layer interfaces)
- `/src/main/java/com/example/service` (Service layer for business logic)
- `/src/main/java/com/example/utils` (Utility classes)
